# Manufacturer prefixes

Each VILKAS-compatible receiver announces a 2-character prefix (`A–Z`, `0–9`) in `PKT_OFFER` and `PKT_TELEMETRY`. The remote shows it in the robot name, e.g. `DV-7K2QF`.

The prefix identifies who **built or sold** the receiver. It isn't a security feature.

| Prefix | Maker | Notes |
|---|---|---|
| `LB` | [Lithuanian Bots](https://lithuanianbots.com/) | **Main distributor** of official VILKAS hardware |
| `DV` | DV Electronics | Designer and maker of VILKAS. Boards sold directly. |
| `XX` | *(reserved)* | Prototypes / personal builds. Use this if you don't plan to distribute boards. |

To request a prefix, open an issue with your name or club and the prefix you'd like.
